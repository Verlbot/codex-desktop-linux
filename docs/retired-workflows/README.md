# Retired GitHub Actions definitions

These eight definitions were removed from `.github/workflows/` when the Verlbot
fork retired on September 16, 2026. GitHub does not execute workflows from this
directory. Repository Actions are also disabled.

The files remain as historical fixtures for the existing workflow validation
and smoke tests. Do not restore or dispatch them. The hourly DMG build schedule,
Nix refresh, cache publishing, CI, and repository maintenance automation are retired.
